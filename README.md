# Presentations

Veysel Murat Görken'in eğitim, atölye ve konferans materyalleri. İki ana program altında toplanmıştır.

## DLtoAI

| Klasör | İçerik |
|---|---|
| [`DLtoAI/CNN`](DLtoAI/CNN) | Convolutional Neural Networks dersi: ders defterleri, kurs materyalleri, YOLO atölyesi, görsel üretim araçları |
| [`DLtoAI/SesTespiti`](DLtoAI/SesTespiti) | Ses sınıflandırma demosu (havlama tespiti) ve örnek ses verisi |

## Quantum Bootcamp

| Klasör | İçerik |
|---|---|
| [`QuantumBootcamp/DL`](QuantumBootcamp/DL) | Deep Learning MasterClass sunumları, içerik planı, anlatım metinleri, görseller |
| [`QuantumBootcamp/LLM/highlevel`](QuantumBootcamp/LLM/highlevel) | LLM MasterClass (high-level): sunum, sunucu metni, attention/prompt/RAG/fine-tune atölyesi |
| [`QuantumBootcamp/LLM/lowlevel`](QuantumBootcamp/LLM/lowlevel) | LLM MasterClass (low-level): sunum, LoRA eğitim atölyesi, n8n notları |
| [`QuantumBootcamp/YuzAnalizi`](QuantumBootcamp/YuzAnalizi) | Colab yüz analizi uygulaması |

## Notlar

- Sunumların yalnızca en güncel sürümleri repoda tutulur; ara sürümler yerel arşivdedir.
- Atölye klasörlerindeki `.log` dosyaları derste yapılan gerçek koşuların kaydıdır, bilerek saklanmıştır.
- Eğitilmiş model ağırlıkları (`*.safetensors`) repoda tutulmaz; atölye adımları çalıştırıldığında yeniden üretilir.
